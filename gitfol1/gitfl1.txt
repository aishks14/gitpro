The Three Areas
------------------------------------------
Working folder : files as you see and edit them on disk
Staging area   : edits picked for the next commit (git add)
Repository     : committed history, saved for good (git commit)

------------------------------------------
Undoing Changes
------------------------------------------
git restore <file>           -> discard uncommitted edits in a file
git restore --staged <file>  -> unstage a file but keep its edits
git commit --amend           -> fix the message of the last commit
git revert <commit>          -> undo a commit with a new commit
