This file is for practising "git switch", the newer and clearer
command for moving between branches and creating new ones.

------------------------------------------
Switch Commands
------------------------------------------
git switch <branch>        -> move to an existing branch
git switch -c <branch>     -> create a new branch and move to it
git switch -              -> jump back to the previous branch
git switch --detach <id>   -> look at an old commit without a branch
