Purpose
------------------------------------------
This is the first sample file in Folder 2. Use it to practise
moving a branch backwards with "git reset" and recovering lost
commits with "git reflog".

------------------------------------------
Reset Modes
------------------------------------------
git reset --soft HEAD~1   -> undo the commit, keep edits staged
git reset --mixed HEAD~1  -> undo the commit, keep edits unstaged
git reset --hard HEAD~1   -> undo the commit and discard the edits
