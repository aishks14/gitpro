Purpose
------------------------------------------
Where to read more about each topic in git-learning-guide.txt.
The first part lists general resources; the second part maps each
section of the guide (A1-A14, B1-B23) to its official manual page.

------------------------------------------
Official Documentation
------------------------------------------
Git home page          : https://git-scm.com
Reference manual       : https://git-scm.com/docs
Pro Git book (free)    : https://git-scm.com/book/en/v2
Git glossary           : https://git-scm.com/docs/gitglossary
Everyday Git           : https://git-scm.com/docs/giteveryday
Git tutorial           : https://git-scm.com/docs/gittutorial
GitHub Docs            : https://docs.github.com
GitHub Git guides      : https://github.com/git-guides

Built-in help, no internet needed:
git help <command>     -> full manual page, e.g. git help rebase
git <command> -h       -> short list of options

------------------------------------------
Interactive Practice
------------------------------------------
Learn Git Branching    : https://learngitbranching.js.org
  Visual exercises for branch, merge, rebase and cherry-pick.
GitHub Skills          : https://skills.github.com
  Short guided courses run inside GitHub repositories.
Oh My Git!             : https://ohmygit.org
  A game that shows the commit graph as you type commands.

Tutorials and Guides
------------------------------------------
Atlassian Git tutorials : https://www.atlassian.com/git/tutorials
MIT Missing Semester    : https://missing.csail.mit.edu/2020/version-control/

Dangit, Git!?!          : https://dangitgit.com
  Plain-language fixes for common mistakes.
Git cheat sheet (GitHub): https://education.github.com/git-cheat-sheet-education.pdf
